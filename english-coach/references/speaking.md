# Speaking Reference — English Coach

> **Core idea**: Natives don't speak word-by-word. They speak in *flow* — sounds connect, weaken, and blend.

*Based on existing Intonation.md notes, expanded with full system.*

---

## 1. Connected Speech — Linking Rules

### Rule 1: Consonant + Vowel → Link them
When a word ends in a consonant sound and the next starts with a vowel, they fuse.

| Written | Sounds like | Example |
|---------|-------------|---------|
| "an apple" | "uh-NAP-ul" | 「アナプル」 |
| "pick it up" | "PIK-ih-DUP" | 「ピキダップ」 |
| "turn it on" | "TUR-ni-DON" | 「ターニドン」 |
| "our event is" | "our-uh-VEN-iz" | 「アウアヴェニズ」|

**Practice**: Say "I figured it out" — it becomes: "I FIG-erd-id-OWT"

---

### Rule 2: T-dropping (Flap T / T-deletion)

**Between vowels → T becomes a soft D (flap):**
| Written | Sounds like |
|---------|-------------|
| "water" | "WAH-der" |
| "better" | "BEH-der" |
| "letter" | "LEH-der" |
| "get it" | "GEH-did" |

**After N → T disappears:**
| Written | Sounds like |
|---------|-------------|
| "want to" | "WAN-uh" (「わな」) |
| "don't want to" | "dohn WAN-uh" (「どんわな」) |
| "didn't want to" | "DIH-dn WAN-uh" (「でぃんわな」) |
| "our event is" | "our-uh-VEN-iz" (n dropped, t→z linked) |

---

### Rule 3: D-dropping

**After N or before consonant clusters → D weakens or disappears:**
| Written | Sounds like |
|---------|-------------|
| "and I" | "an-I" (「あない」) |
| "and the" | "an-the" |
| "find out" | "FYN-owt" |

---

### Rule 4: T+Y and D+Y → CH and J sounds

| Written | Sounds like |
|---------|-------------|
| "want you" | "WAHN-choo" (「ウォンチュー」) |
| "appreciate you" | "uh-PREE-shee-AY-choo" (「アプリシエイチュー」) |
| "did you" | "DIJ-oo" (「ディジュー」) |
| "would you" | "WUJ-oo" (「ウジュー」) |

## 2. Reductions (Short Forms Natives Actually Use)

> Reductions are **not lazy speech** — they ARE the natural form in spoken English.

| Written form | Reduced form | Kana guide |
|-------------|-------------|-----------|
| going to | gonna | ガナ |
| want to | wanna | ワナ |
| have to | hafta | ハフタ |
| has to | hasta | ハスタ |
| supposed to | sposeta | スポウスタ |
| kind of | kinda | カインダ |
| sort of | sorta | ソータ |
| a lot of | alotta | アロッタ |
| should have | shoulda | シュダ |
| would have | woulda | ウダ |
| could have | coulda | クダ |
| don't | dohn | ドン（t消える） |
| doesn't | duhzn | ダズン |
| didn't | didnt | ディドゥン |
| I don't know | I dunno | アイダノウ |
| give me | gimme | ギミ |
| let me | lemme | レミ |

**Key rule**: Reductions happen *inside sentences*, not alone. "Gonna" alone sounds odd; "I'm gonna go" is natural.

## 3. Intonation Patterns

### Statement (falling ↘)
"I'll fix that tomorrow." → voice falls at "tomorrow"

### Yes/No Question (rising ↗)
"Did you push the changes?" → voice rises at "changes?"

### Wh-Question (falling ↘)
"What's the status?" → voice falls at "status?"

### List (rise, rise, fall ↗ ↗ ↘)
"We need to fix the auth, update the tests, and deploy." → rise at each item, fall at last.

### Emphasis (stress the KEY word)
"I didn't say it was *your* fault." (stress "your" = implying someone else's)
"*I* didn't say it was your fault." (stress "I" = implying someone else said it)

## 4. Chunk Reading

> Natives don't process word-by-word — they read/hear in *meaning chunks*.

**Example from chank.md:**
`i just want to make sure we're on the same page regarding our roles`

Break it into chunks:
- `i just want to make sure` [chunk 1 — purpose]
- `we're on the same page` [chunk 2 — state]
- `regarding our roles` [chunk 3 — scope]

**Practice method**: When reading aloud, pause briefly between chunks (not between words). This makes speech sound natural and is how natives *understand* fast speech too.

**Common IT chunks to internalize:**
- `pull it up` / `log it out` / `push it live`
- `spin it up` / `take it down` / `roll it back`
- `let me know` / `get back to you` / `take a look`

## 6. Practice Prompts

Use these with macOS Dictation (Fn Fn to activate):

1. Describe a bug you fixed today — out loud, in English. Type what you said.
2. Say: "I should've caught that earlier, but I didn't notice the edge case."
3. Say: "We're gonna need to refactor this before we can scale it up."
4. Read a Git commit message aloud — then say it again with natural reductions.
